📊 E-Commerce Sales Dashboard

## 📌 Project Overview

This project is an **E-Commerce Sales Dashboard** developed using **Microsoft Excel and Power BI** to analyze sales data and generate meaningful business insights.

The dashboard helps understand overall sales performance, identify top-performing products and categories, analyze sales trends, and evaluate business performance using interactive visualizations and KPIs.

---

## 🎯 Project Objective

The main objective of this project is to transform raw e-commerce sales data into an interactive dashboard that can help businesses:

* Monitor overall sales performance
* Analyze revenue and profit trends
* Identify top-performing products and categories
* Understand customer and regional sales patterns
* Compare sales performance over time
* Make data-driven business decisions

---

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data storage and initial data preparation
* **Power Query** – Data cleaning and transformation
* **Microsoft Power BI** – Dashboard development and visualization
* **DAX** – Calculated measures and KPIs
